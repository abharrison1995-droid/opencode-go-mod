# Codex companion agent routing

This directory is the **Codex desktop / CLI variant** of the OpenCode Go Mod project. Its package is `codex-companion/plugin.json` plus `mcp.json`, `skills/`, `shared/` and `server/`. The canonical shared provider modules live in the repository's `bridge-core/`; `scripts/sync-codex-shared.mjs` generates the package-local copies, and CI checks that they match. The MCP manifest points to the bundled `server/dist/index.mjs`, so keep that bundle updated with `npm run check`. The **Claude Code variant is at the repository root** (`.claude-plugin/`, `hooks/`); it is **not** installed here.

When a user asks you to install this mod for Codex, install THIS package; when a user asks for Claude Code, go back to the repository root and follow the Claude installer, even if you are a Codex agent. Read `../docs/INSTALLATION.md` before installation. Codex uses this package's MCP, skill and optional loopback dashboard; it does not load Claude's sidebar API. Verify plugin discovery, `bridge_usage` and a read-only MCP call before declaring success. For edits, `start_pipeline_job` requires `BRIDGE_ENABLE_WRITES=1`, uses a preserved isolated worktree and never merges or pushes. The maximum concurrent job count is eight.
